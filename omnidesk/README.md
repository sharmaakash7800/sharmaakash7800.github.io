# OmniDesk PWA

Upload/commit these files to the root of your GitHub Pages `omnidesk` repository:

- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `icons/icon-192.png`
- `icons/icon-512.png`

Then open:
https://sharmaakash7800.github.io/omnidesk/

Android / Desktop Chrome or Edge:
- Open the site.
- Open OmniDesk menu and tap **Install OmniDesk App** when shown,
  or use the browser's **Install app / Add to Home Screen** option.

iPhone / iPad Safari:
- Open the site in Safari.
- Share -> Add to Home Screen.
- Launch from the Home Screen.

Important:
The OmniDesk shell can be cached for offline opening, but external Google Sheets,
Looker Studio reports, Google Apps Script links and other external sites still require
their own network access.
